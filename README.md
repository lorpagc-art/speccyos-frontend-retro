# Speccy OS E5 Ultra - Imperial Edition 🚀 (V 0.5.1 Aether Ultra)

**Speccy OS E5 Ultra** es un frontend de emulación de alto rendimiento diseñado para dispositivos Android, centrado en la optimización extrema del hardware y una experiencia de usuario inmersiva tipo consola.

Esta versión introduce el motor visual **AETHER ULTRA (v0.5.1)**, con efectos de profundidad 3D, resplandor neón dual y una integración cinematográfica de diseños propios.

---

## 🚀 Novedades de la Versión 0.5.1 (Aether Ultra & Neon Engine)

### 🌌 Motor Visual AETHER ULTRA
- **Rotación 3D Dinámica**: El carrusel de sistemas ahora utiliza transformaciones en el eje Y para crear una sensación de profundidad real al desplazarse.
- **HUD de Sistemas Estilizado**: Las tarjetas de Ajustes, IA y Hardware han sido rediseñadas con un diseño "Glassmorphic" (cristalografía) que incluye auras pulsantes tras los iconos.
- **Filtro Atmosférico Cinematográfico**: Los fondos ahora se tiñen dinámicamente según el "ADN" del sistema seleccionado, aplicando desenfoque gaussiano de 40dp para resaltar las tarjetas.
- **Diseños Propios Cyberpunk**: Integración total con la galería interna de arte propio, adaptada a todos los formatos y consolas.

### 🌈 Neon Dual-Engine
- **Perfiles Bicolores**: Introducción de 6 presets de color neón (Cyber, Acid, Magma, Vapor, Ghost, Classic) que mezclan tonos primarios y de acento.
- **Resplandor Dual (Glow)**: Las tarjetas y menús emiten una luz proyectada basada en el color de acento, simulando iluminación ambiental dinámica.
- **Grid de Fondo Reactivo**: El fondo de la interfaz ahora dibuja un entramado de líneas con degradados duales que reaccionan al perfil neón activo.
- **Selector de Interfaz Pro**: Panel de configuración rediseñado para previsualizar y aplicar perfiles de color neón en tiempo real.

---

## 🚀 Características de Versión 0.5.0 (RomScannerTurbo)

### ⚡ Inyección de Potencia Turbo
- **Paralelismo Masivo**: El sistema lanza el escaneo de todas las consolas simultáneamente.
- **Motor Multi-Hilo para Hashes**: Semáforo de 8 hilos para el cálculo de MD5/CRC32, procesando 8 juegos a la vez.
- **Buffer de Datos Optimizado**: Aumento del buffer de lectura a **64KB**, maximizando la velocidad en tarjetas SD.

---

## 🔥 Características de Versiones Anteriores

### 🛰️ Ultra-Scraper Safe Sync V3.6
- **TheGamesDB Integration**: Migración exitosa a TheGamesDB con API Key elite.
- **SmartFix (Levenshtein 2.0)**: Algoritmo de búsqueda difusa para nombres de archivos imperfectos.

### 🧠 IA Architect: Conocimiento Multi-SOC
- **Perfiles de Hardware Dinámicos**: Optimización específica para **Unisoc T620 (E5 Ultra)**, T618, RK3566 y Snapdragon 8 Gen 2.

## 📖 Guía para Desarrolladores (Estructura)
El **Cerebro del Sistema** reside en:
- `ThemeUltra.kt`: Motor visual AETHER con rotación 3D y HUD Glassmorphic.
- `ThemeManager.kt`: Gestor del Neon Engine y perfiles de color dual.
- `RomScanner.kt`: Motor Turbo v0.5.0 con paralelismo masivo.
- `HashUtility.kt`: Utilidades de hashing ultra-rápidas con buffer de 64KB.
- `network/OnlineScraperService.kt`: Motor V3.6 con lógica TheGamesDB y SmartFix.
