# 🕹️ BENUTZERHANDBUCH: SPECCY OS E5 ULTRA (V0.5.1)

Willkommen bei **Speccy OS**, dem ultimativen Frontend, das von Grund auf entwickelt wurde, um das absolute Maximum aus Ihrer Retro-Konsolen-Hardware herauszuholen, speziell optimiert für den Unisoc T620 (E5 Ultra) Chip.

Dieses Handbuch führt Sie durch die grundlegenden und erweiterten Funktionen des Systems.

---

## 🚀 1. ERSTE SCHRITTE

### 1.1. Bibliothek verknüpfen (ROMs)
1. Melden Sie sich beim ersten Start der Anwendung mit Ihrem Google-Konto an.
2. Folgen Sie dem Assistenten, um die **Geräte-DNA** auszuwählen (z. B. GameMT E5 Ultra, Anbernic RG405M usw.). Dadurch wird die automatische Übertaktung kalibriert.
3. Wählen Sie auf dem Bildschirm **"Bibliothek verknüpfen"** den Stammordner Ihrer SD-Karte aus, auf dem Ihre ROMs gespeichert sind.
4. **Empfohlene Struktur:** Ihr Stammordner sollte Unterordner mit den Kurznamen der Systeme enthalten (z. B. `snes`, `psx`, `megadrive`, `mame`).

### 1.2. Der erste Scan
Sobald der Ordner verknüpft ist, führt Speccy OS einen tiefen Scan durch. Abhängig von der Größe Ihrer Bibliothek (es werden über 25.000 Spiele unterstützt) kann dies einige Minuten dauern. Schließen Sie die Anwendung nicht!

---

## 🎮 2. NAVIGATION UND STEUERUNG

Speccy OS ist so konzipiert, dass es zu 100 % mit einem physischen Gamepad bedient werden kann.

*   **D-Pad Links/Rechts:** System wechseln (Konsole).
*   **D-Pad Hoch/Runter:** Durch die Spieleliste des ausgewählten Systems navigieren.
*   **A-Taste (oder START):** Das ausgewählte Spiel starten.
*   **B-Taste:** Zurückgehen oder das aktuelle System verlassen.
*   **Y-Taste:** Ein Spiel als Favorit markieren/entfernen.

### 🤫 Das Geheimnis (Konami Code)
Wenn Sie sich auf dem Hauptbildschirm befinden (Konsolenansicht) und nichts anderes berühren, geben Sie die folgende Sequenz mit Ihrem D-Pad ein:
`↑, ↑, ↓, ↓, ←, →, ←, →, B, A`
Sie werden das versteckte "MATRIX"-Theme freischalten und für heute unbegrenzte KI-Anfragen erhalten!

---

## 🧠 3. DER ARCHITEKT (Künstliche Intelligenz)

Speccy OS enthält eine native KI namens **Der Architekt**, die sich der von Ihnen installierten Spiele bewusst ist.

1.  Drücken Sie die **KI**-Taste (Chat-Symbol) im Bedienfeld.
2.  Sie können nach Cheats, Geschichte oder Empfehlungen fragen, basierend auf den Spielen, die Sie am meisten spielen.
3.  **Trivia Arcade:** Drücken Sie im Architekten auf "TRIVIA SPIELEN". Das System generiert Fragen zur Geschichte der Videospiele. Sammeln Sie Punkte und teilen Sie Ihren Rang (vom *Anfänger* bis zum *Gott der Arcade*) mit Ihren Freunden!

### 3.1. Automatischer Start und Empfehlungen
Der Architekt kann Spiele direkt für Sie starten. Wenn Sie sagen "Ich möchte Super Mario 64 spielen", bereitet er das beste Leistungsprofil vor und öffnet das Spiel automatisch. *Kostenlose* Benutzer haben 1 automatischen Start durch die KI pro Tag (Benutzer von *Imperial/Pro* haben unbegrenzte Starts).

### 3.2. Emulationsassistent und Kerne (Cores)
Die KI kennt Ihre Hardware, deren Einschränkungen und Vorteile perfekt. Sie können sie bitten, automatisch das beste thermische Profil oder einen bestimmten Emulator für eine Konsole zuzuweisen.
*Fehlt ein RetroArch-Kern?* Die KI führt Sie Schritt für Schritt: Öffnen Sie die native RetroArch-App > Hauptmenü > Online-Aktualisierungen > Kern-Herunterlader. Laden Sie ihn herunter, und er wird magisch in den Speccy OS Emulator-Einstellungen erscheinen.

---

## ⚡ 4. AUTO-TUNING UND LEISTUNG

Speccy OS steuert den Prozessor Ihrer Konsole dynamisch, um Batterie zu sparen oder bei Bedarf maximale Leistung zu bieten.

*   **2D-Systeme (GB, NES):** Die Konsole wechselt in den **ECO**-Modus.
*   **32-Bit-Systeme (PSX, N64):** Modus **AUSGEGLICHEN** (BALANCED) oder **LEISTUNG** (PERFORMANCE).
*   **Schwere Systeme (PS2, GameCube, Wii):** Das System aktiviert den Modus **EXTREM**, schaltet den Lüfter ein und entfesselt die volle Leistung des Prozessors.

*Hinweis: Sie können einen manuellen Modus im Abschnitt "GERÄT" (DEVICE) in den Einstellungen erzwingen.*

---

## ☁️ 5. NEBULA SYNC (Cloud-Speicher)

Verlieren Sie nie wieder einen Spielstand! Wenn Sie ein PRO/Imperial-Benutzer sind, können Sie **Nebula Sync** in den Einstellungen (Abschnitt KONTO) aktivieren.

*   Beim Starten eines Spiels prüft Speccy OS unsichtbar, ob Sie einen neueren Spielstand auf Ihrem Google Drive haben und lädt ihn automatisch auf Ihre Konsole herunter.
*   *Ihre Spielstände werden für maximale Sicherheit in einer versteckten Partition (AppData) von Drive gespeichert.*

---

## 🎨 6. VISUELLE ANPASSUNG

Gehen Sie zu **Einstellungen > SCHNITTSTELLE** (INTERFACE), um die DNA Ihrer Konsole zu ändern:
*   **Themes:** Wählen Sie zwischen `Ultra HD` (3D-Karten), `Pure Immersive` (Finsternis und Vollbildkunst) oder `Speccy OS` (klassischer Android-Stil).
*   **Neons:** Ändern Sie die Akzentfarbe der gesamten Schnittstelle (Cyber, Vaporwave, Magma usw.).
*   **CRT-Effekt:** Aktivieren Sie klassische Kathodenstrahlröhren-Linien über den Spielvideos.
*   **Attract Mode:** Wenn Sie die Konsole eingeschaltet lassen, ohne 60 Sekunden lang etwas zu berühren, beginnt Speccy OS mit der Wiedergabe zufälliger Videos Ihrer Spiele im Vollbildmodus, genau wie bei einem echten Spielautomaten. Drücken Sie eine beliebige Taste, um das Menü zu verlassen!

---

## ⚙️ 7. SCRAPER (Box Arts und Videos)

Speccy OS sucht automatisch nach Informationen zu Ihren Spielen, aber um hochwertige Box Arts und Videos (WebP/MP4) zu erhalten:
1.  Gehen Sie zu **Einstellungen > SCRAPER**.
2.  Wählen Sie Ihren Anbieter aus (empfohlen: *ScreenScraper*).
3.  Geben Sie Ihre Anmeldeinformationen ein (Sie können auf deren Website ein kostenloses Konto erstellen).
4.  Drücken Sie auf **GLOBALES SCRAPING ERZWINGEN**. Das System arbeitet im Hintergrund, um die Videos herunterzuladen.
